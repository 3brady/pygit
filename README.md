# pygit

### A version Control System ( Git wannabe ) written in python while trying to understand how git works under the hood

# contributing

## 1 - clone the repo

```bash
git clone https://github.com/3brady/pygit.git
cd pygit
```

## 2 - set up the environment 

```bash
python3 -m venv env
source env/bin/activate
```

## 3 - installing the requirements

```bash
pip install -r requirements.txt
```

## 4 - install pygit in editable mode

```bash
pip install -e .
```

after that you are good to go, run `pygit` to try it out
